# Steam Library Injector 🚀

Um aplicativo em Python com interface gráfica (PySide6) para injetar e gerenciar atalhos customizados na biblioteca da Steam no Linux.

## ✨ Funcionalidades
- Interface simples e intuitiva feita em PySide6.
- Manipulação direta e segura do arquivo de configuração `shortcuts.vdf` da Steam.
- Totalmente portátil (distribuído como AppImage).

## 📦 Como Usar (Para Usuários)
Se você quer apenas usar o programa, não precisa compilar nada:
1. Vá na aba **Releases** aqui no GitHub.
2. Baixe o arquivo `.AppImage` mais recente.
3. Dê permissão de execução ao arquivo (via terminal ou clicando com o botão direito -> Propriedades):
   ```bash
   chmod +x Steam_Library_Injector-x86_64.AppImage
